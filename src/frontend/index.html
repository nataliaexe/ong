Sobre a ONG

Feito para emocionar sem perder clareza

A base agora conversa com o que voce descreveu: resgate, adotados, ajuda urgente, futuro painel admin e uma identidade mais memoravel.

Nossa historia

A FlorAnimal nasceu para acolher animais em situacoes de risco e criar caminhos de reabilitacao, visibilidade e adocao responsavel. O novo layout tenta mostrar esse cuidado em cada detalhe.

Equipe voluntaria: estrutura pensada para destacar protetoras, parceiras e apoiadoras.
Foco visual: natureza, calor humano, urgencia quando precisa e leveza quando a historia floresce.

Base para o painel admin

O site ja esta organizado para ganhar uma area administrativa simples, onde as responsaveis poderao cadastrar animais, atualizar adotados e trocar os casos urgentes sem depender de codigo toda vez.

Animais: adicionar, editar, remover e marcar como adotado.
Adotados: publicar historia, data, status e depoimento da familia.
